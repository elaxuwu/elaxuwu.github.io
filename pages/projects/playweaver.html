Giới thiệu Overview

[?] Vấn đề [?] The Problem

Một ý tưởng game có thể rất hào hứng trong năm phút đầu, rồi việc cài engine, viết boilerplate và tìm placeholder art hút sạch năng lượng trước khi prototype kịp tồn tại. A game idea can feel exciting for five minutes, then engine setup, boilerplate, and placeholder art drain the energy before the prototype exists.

[!] Giải pháp [!] The Solution

PlayWeaver biến một ý tưởng đơn giản thành bản thiết kế game trực quan, rồi tạo prototype HTML5 Canvas ngay bên cạnh bảng thiết kế. Người dùng có thể trò chuyện với AI, thêm ảnh tham khảo, sắp xếp cơ chế bằng node và thử ngay kết quả trong khung iframe. PlayWeaver turns a plain idea into a visual game plan, then generates an HTML5 Canvas prototype beside the design board. Users can chat with the AI, add image references, map mechanics as nodes, and instantly test the result in an iframe preview.


GHI CHÚ: Mã nguồn được công khai tại github.com/elaxuwu/PlayWeaver. NOTE: The source code is public at github.com/elaxuwu/PlayWeaver.

Tính năng Features

FEAT_01 FEAT_01

Bảng thiết kế dạng node Node-Based Design Board

Trình chỉnh sửa tạo một canvas node 2D cho cơ chế, nhân vật, bối cảnh, điều kiện chiến thắng và ảnh tham khảo. The editor creates a 2D node canvas for mechanics, characters, settings, win conditions, and visual references.

FEAT_02 FEAT_02

AI điều khiển giao diện AI UI Executor

DeepSeek thông qua featherless.ai đọc đoạn chat và xuất các lệnh JSON chặt chẽ để thao tác trực tiếp lên bảng thiết kế. DeepSeek through featherless.ai reads chat and emits strict JSON commands that physically manipulate the board.

FEAT_03 FEAT_03

Bộ tạo game HTML5 tức thì Instant HTML5 Game Generator

OpenAI tạo và viết lại từng phần mã game Canvas có thể chơi được dựa trên trạng thái bảng, HTML hiện tại và URL asset đã tải lên. OpenAI generates and incrementally rewrites playable Canvas game code from the board state, existing HTML, and uploaded asset URLs.

FEAT_04 FEAT_04

Autosave an toàn cho asset Asset-Safe Autosave

Ảnh tải lên được chuyển sang ImgBB, còn Upstash Redis lưu trạng thái dự án gọn sạch để prototype có thể khôi phục mà không bị quá tải Base64. Uploaded images move to ImgBB while Upstash Redis stores clean project state, keeping prototypes recoverable without Base64 overload.
